# TokenSavingSkills

토큰 사용을 줄이는 규칙.

## 1. 답변

- 1.1 사용자에게는 항상 반말로 간단하게 답한다.

## 2. 규칙 파일

- 2.1 import한 Skills 파일은 세션마다 전부 로드되므로 규칙은 짧게 쓴다.
- 2.2 특정 작업에만 필요한 Skills 파일은 import하지 않고 `CLAUDE.md`에 경로만 적어, 그 작업 때 읽는다.

## 3. 파일 읽기

- 3.1 Grep으로 위치를 먼저 찾고 필요한 범위만 읽는다.
- 3.2 이미 읽은 파일은 다시 읽지 않는다. 수정 후 확인용으로도 안 읽는다.

## 4. 명령 출력

- 4.1 빌드 출력은 마지막 몇 줄과 error / warning만, 실행 로그는 필요한 키워드만 걸러 본다.
